# X2 .66: карта D1 и независимая локализация

Состояние на 20.10.2026: перенос карты и запуск локализации выполнены;
навигация с движением и точность достижения цели **не приняты**.

## 1. Гипотезы и подтверждения

1. Подтверждено: фирменные LocalizationModule, MappingModule,
   RelocalizationModule, MapManagerModule не запускаются: license denied.
   Процесс SLAM существует, но не публикует локализационную одометрию.
2. Подтверждено: исходный YAML first_map с free_thresh=0.25 меняет смысл
   пикселей 205 при чтении стандартным Nav2. Загрузчик QORGAN на D1 отдельно
   возвращает этим пикселям unknown. Простое копирование YAML недостаточно.
3. Подтверждено: глобальная инициализация AMCL пока не установила принятую
   физическую позу X2. Наличие map->odom не доказывает правильную локализацию.
4. Требуют проверки: переносимость горизонтального среза между D1/X2,
   неоднозначность геометрии, калибровка карты, ошибки при ходьбе и остановке.

## 3. Установленные причины

Отказ фирменной локализации — проверка лицензии при запуске модулей,
а не отсутствие переданных файлов карты. Перенос на открытый стек устраняет
эту зависимость для нового процесса, но не восстанавливает фирменные модули.

Несовместимость семантики карты — специальная обработка оттенка 205
в D1 QORGAN map_io.py, отсутствующая в стандартном trinary Map Server.

Причина недостаточной точности движения пока не установлена: end-to-end
движение нового стека не выполнялось.

## 4. Принятое направление

По выбору пользователя: независимый Nav2/AMCL, без фирменной локализации.
С .89 переиспользованы ARM64 FAST-LIO с обработчиком AIMA PointCloud2,
сортировкой per-point timestamps и отключённым накоплением runtime-логов,
а также gravity-level bridge и совместимые пакеты Nav2 1.1.18.

Самописный reloc.py, сглаживание глобальных поправок и fallback на другую
карту не перенесены. Исследовательский planner с .89 не принят как готовый:
его отчёт содержит провал независимой проверки clearance.

## 7. Сценарии, необходимые до приёмки

1. Nominal: физическая начальная поза, совмещение стен/сканов, tracking,
   цель с заданной ориентацией; ошибка измеряется внешним способом.
2. Разные места старта и курсы, короткие и длинные маршруты, разные
   разрешённые скорости; повторяемость и p95/max ошибки остановки.
3. Edge: стены, unknown, край карты, узкие проходы, недостижимая цель.
   Проверять непрерывный swept footprint, а не только центры клеток пути.
4. Recovery: отмена, смена цели, операторский takeover, перезапуск
   локализации без принятия старого преобразования за новую позу.
5. Сбои: LiDAR/IMU/TF/odom loss и timestamp jumps; запрет движения при
   недостоверном состоянии, без выдумывания нулевой одометрии.
6. Руки/корпус/стопы: динамический габарит и центр управления;
   текущий base_footprint моста — виртуальная проекция IMU.
7. Скорость: исходный bridge не заполняет twist/covariance; его выход
   нельзя объявлять готовой обратной связью скорости для controller.
8. Другие карты: проверка идентичности карты, origin/resolution и повторная
   локализация; не переносить координаты между разными map frames.

Оператор сообщил: .66 возле B на старой схеме (примерно x=1, y=-8 м),
направлен на A/D. Однократно введена начальная гипотеза (1,-8,52.5°),
standard deviations (1 м,1 м,15°). Начальная оценка AMCL после seed:
(0.886,-7.888,54.20°), variances (0.803,0.996,0.0595).
Она не является принятой физической позой.

При первом seed журнал сообщил extrapolation into future: wall-clock stamp
был примерно на 49 мс новее последнего local TF. AMCL принял seed, но
предупреждение зафиксировано, а не подавлено. Для будущих неподвижных
commissioning seeds helper использует stamp фактически полученного local
TF. Это не устранило внутренний callback-time lookup AMCL: предупреждение повторилось при плановом перезапуске. Исправление времени в upstream AMCL пока не подтверждено; допуски TF не увеличивались.

Оператор согласовал и выполнил поворот пультом. Сохранённый участок:
552 local odometry samples, 276 scans, диапазон yaw 87.25°, конечная разница
курса 14.62°, максимальное перемещение IMU 0.135 м. Это измерения LIO,
а не независимая физическая эталонная траектория. AMCL дал 9 сообщений,
включая retained начальную оценку, и остался с неопределённостью порядка
0.8 м. Локализация не принята.

Ошибка стенда: анализатор открыл ещё записываемую SQLite bag; recorder
завершился с database is locked. SQLite integrity_check сохранённого
участка дал ok (25339 сообщений), metadata восстановлена штатным reindex.
Этот опыт помечен частичным. Анализатор теперь отказывается читать bag
без metadata.yaml до обращения к БД; отдельный regression check прошёл.
Следующая 15-секундная raw-запись закрылась штатно.

На .66 выполнено сравнение dense/sparse на одной raw-записи. Первый стенд
не обеспечивал matching до начала playback и использовал DDS default SHM;
прогоны стартовали с разных сканов, обнаружены предупреждения insufficient
SHM. Их разницу одометрии нельзя приписывать одному dense flag. Стенд
исправлен: publisher matching до первого сообщения, штатная SHM capacity
из DDS-профиля робота, UDP только loopback, отдельный domain87 и remap
hardware input topics. Промежуточные невалидные результаты сохранены.

Официальная AimDK указывает 1310(H) x 460(W) x 210(L) мм. Этот статический
размер не является сертифицированной огибающей ходьбы и взмахов рук.
Источник: https://x2-aimdk.agibot.com/en/dev/about_agibot_X2/robot_specifications.html
Модель URDF выбирается по шильдику согласно:

## 8. Вердикт

Карта перенесена и её семантика для стандартного Nav2 проверена.
Независимая локализация запущена; для принятой позы и движения ещё нужны
физическая привязка, управляющая база, валидная скорость, footprint,
controller/MC adapter и испытания с оператором. Утверждать, что навигация
уже работает точно из любой точки и регрессий нет, нельзя.

## Завершение текущего диагностического этапа

В full_turn_dense_02 записано 1164 local odom, 582 scans и9 сообщений AMCL.
Диапазон yaw22.48°, перемещение IMU0.944м. Оператор подтвердил: робот
реально прошёл примерно метр с небольшим поворотом, полного круга не было;
полный поворот сейчас выполнить невозможно. Не считать этот тест круговым.

Независимый MC leg_odom на том же участке:20175 samples, конечное
перемещение0.508м, yaw span22.85°. Курс согласуется с LIO, трансляция
существенно расходится. Приблизительное наблюдение оператора поддерживает
LIO, но сантиметровой калибровкой не является. Коэффициент масштаба MC
не изменялся. Основной кандидат одометрии нового стека — FAST-LIO.

Последняя записанная оценка AMCL:(1.696,-7.895,64.22°), variances
(0.585м²,0.681м²,0.150рад²). Она остаётся НЕПРИНЯТОЙ. Геометрическая
совместимость scan/map, калиброванная управляющая база и скорость,
динамический footprint, planner/controller и MC execution ещё требуют
проверки. Для точного прибытия недостаточно задать малый goal_tolerance.

Штатный installed perception URDF x2t2 сохранён в evidence:40 links,
24 имеют collision geometry. Само отсутствие collision у части links не
доказывает неполную внешнюю оболочку; применимость модели к swept footprint
ходьбы не установлена. Статические размеры AimDK не объявлялись
динамическим габаритом. Подтверждённого production footprint пока нет.

На .66 оставлен вручную запущенный диагностический FAST-LIO/bridge/
Map Server/AMCL; автозапуска нет. Все конечные bag recordings и replay
процессы завершены. Новый стек не публикует скорость и не регистрирует MC
source. D1 и reference .89 использовались только для чтения/копирования;
их сервисы и конфигурации не изменялись.

Следующий реальный шаг: измеренный линейный и поворотный тест с оператором,
проверка совпадения известных стен/ориентиров со сканом и принятие
локализации. Затем подготовка и приёмка управляющего адаптера и полного
Nav2 пути. Задача навигации к точной координате из произвольного старта
остаётся незавершённой; положительный финальный вердикт не выдан.
