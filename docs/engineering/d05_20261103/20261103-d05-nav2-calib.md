## Tool behaviour (nav2_calib.py)
Reads live params (GetParameters, read-only) -> refuses target outside [0.05, envelope] (exit 2) -> read-only preflight
(GC fresh/ready/not busy/not latched; adapter live+registered, no latch, no foreign MC pub; controller subscribed to
speed_limit; no other speed_limit publisher) (exit 3) -> starts recorder -> publishes percentage limit (1 Hz refresh) ->
waits for operator RViz goal via GC status busy -> post-roll -> restores NO_SPEED_LIMIT -> stops bag -> meta JSON
(live params, events, goal timing, limit_honored, steady_cmd_s, ramps, operator tape fields). Abort while goal busy:
leaves the LOWER limit (safe side) + prints `--restore-only` command. Never sends goals/velocity/service calls.
