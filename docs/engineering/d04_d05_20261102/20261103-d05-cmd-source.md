## Admission (documented, not bypassed)
Adapter drops commands until motion_armed, set only by ~/arm_motion (normally called by GC for a new goal). arm_motion needs: registered live adapter, idle, MC fresh/standing/FSM ok, map->odom TF <1 s, trust true <0.6 s, no foreign MC publisher, source not pnc/foreign.
The tool NEVER calls services: it refuses unless live+registered+armed+idle+latch ""+ready, status <1 s old, GC not busy/latched, no other publisher on cmd topic, adapter subscribed, no non-zero 'rc' velocity in last 1 s (fails closed without aimdk_msgs).
