## 6. Symptom / proximate / root cause
- Symptom: X2 walks ~1.6× faster than Nav2 commands (LIVE-2: 3.11 m vs 1.90 m integral); native odom/leg reports ~8-12 % less than tape.
- Proximate: MC LOW-speed locomotion produces ~0.48-0.50 m/s for a 0.30 m/s command (and ~0.76 for 0.80); command reaches MC unaltered.
- Root cause (D-05): MC forward speed characteristic is nonlinear (offset-like / minimum-gait-speed behaviour in LOW mode), not unity-gain; adapter assumes unity. Root cause (D-06): leg odometry under-estimates stride length, speed- and turn-dependent (not a single scale factor).
