## Сбой первой записи

Стандартный rosbag2 recorder session 72324 завершился аварийно:
SqliteException, database is locked (SQLITE_BUSY).
Перед этим Codex выполнял read-only SQL-запросы к открытой базе для проверки
записи; они могли удержать read lock и сорвать запись с нулевым ожиданием
блокировки. Это ошибка диагностики; отсутствие физического движения нельзя
выводить из прекратившихся данных. Оператору сразу передана команда не начинать
проход/остановиться; оператор сообщил, что проход уже завершён и робот стоит.

Закрытая после аварии база восстановлена штатным `ros2 bag reindex`.
Траектория не считается непрерывно записанной. Больше не читать открытую
SQLite recorder; состояние recorder проверять через process handle/stdout,
наличие данных — отдельным ROS subscriber. Анализ SQL только после закрытия.

сохранённая ДО прохода. Конечная опора: отдельная пассивная подписка, 31 sample
после подтверждённой остановки. PID/start time FAST-LIO 314339 и level_bridge

reset через пропуск записи независимо не доказано.

расхождение длины -0.082332 м. Изменение yaw = 0.001676 рад (~0.096°).

не измерялось; lateral не называть доказанным боковым дрейфом.
Неопределённость физической разметки/совмещения пока не численно задана.
