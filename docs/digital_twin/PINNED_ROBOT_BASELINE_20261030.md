## Симуляция пока автоматически НЕ переключена

Проверенный локальный `/home/adn/QazBot/digital_twin/.env` задаёт `TWIN_BACKEND=../../control_backend`, `TWIN_MAP_DIR=../../control_backend/ws/src/maps/main_office`. Это старый локальный checkout, а не эта новая ветка. Рабочие файлы пользователя не перезаписывались, контейнеры не перезапускались и образы не пересобирались.

В `digital_twin/docker/compose.yaml` обычный сервис `stack` берёт код, запечённый в образ при сборке. Dev-сервис монтирует `ws/src`. Поэтому сменить Git-ветку недостаточно: необходимо указать новый build context/volume, карту и пересобрать stack image, затем проверить код **внутри** контейнера. Dockerfile дополнительно изменяет копию `nav_control.launch.py`; эти изменения должны быть явно учтены в сравнении.

Обнаружено отдельное расхождение launch: локальный `x2_twin_bringup/launch/amcl.launch.py` содержит `max_beams=1440` и не задаёт актуальные alpha/update thresholds из физического профиля (180 beams). Он запускает настоящий AMCL, но не импортирует актуальный словарь параметров из production launch. Подпись о production parity в docstring не доказывает текущий паритет. Также launch двойника отдельно задаёт Trust/plant topic names и частоты. До проверки этих параметров нельзя считать, что актуальный backend сам сделал симуляцию эквивалентной роботу.

Перед следующим SIM-прогоном:

1. Выбрать эту опубликованную ветку/конкретный commit как источник backend.
2. Пройти проверку 73 SHA256 на хосте; задать установленную D1-карту из этой ветки.
3. Согласовать launch AMCL/Trust с `actual_parameters.json`, включая одометрию native_imu. Не использовать truth localization для проверки локализации.
4. Пересобрать/выбрать правильный образ и проверить код, карту и live-параметры внутри контейнера. Не направлять запуск на DDS физического робота.
5. Отдельно зафиксировать любые intentional sim overrides и версии Nav2/SDK.

Таким образом, установленный backend сохранён в Git и может быть проверен побайтово; готовность текущей симуляции к воспроизведению этой версии пока не заявляется.
