# Qazbot Control Backend — X2 на карте D1

Рабочий источник: ~/control_backend на X2 .66. Локальные архивные копии не являются рабочим кодом.

**Сейчас запрещены команды движения реальному роботу:** разрешены пассивная проверка, изолированные тесты на модели и сухой стек без публикации в MC.
См. docs/CURRENT_CONSTRAINTS.md. Единственный реальный шаг в MC — S1 (один ADD источника, без скоростей). `sdk_qazbot_nav2` с приоритетом 30 это
конфигурация, а не разрешение регистрировать источник. Реальные цели, `live:=true` и регистрация источника только по явному «go» оператора на каждый шаг.

Состояние (2026-10-21): карта D1 `first_map` новая, производная для Nav2 `ws/src/maps/first_map_nav2_v2`. Сухая цепочка RViz `goal_pose` →
координатор (шлюз владения целью) → единственные `bt_navigator`/планировщик/RPP/сглаживатель → адаптер `live:=false` → модель проверена сквозным прогоном
(`nav_e2e_real_dryrun_08`: 160/160). Сухой стек запущен на аппаратном DDS без наших издателей в MC. Не доказано: пороги доверия локализации (F0), динамический габарит (F1),
любая реальная цель. Открытые дефекты: docs/X2_NAV2_CONTROLLER.md, раздел 8.

Изолированный запуск модели, без MC и аппаратной локализации (домен 87, localhost; по умолчанию реальная цепочка с настоящими адаптером `live=false` и trust):

```bash
cd ~/control_backend
bash tests/nav_e2e/run_model.sh NEW_UNIQUE_RESULT_NAME          # реальная цепочка (160 проверок в последнем полном прогоне)
bash tests/nav_e2e/run_model.sh --legacy NEW_UNIQUE_RESULT_NAME  # легаси-фикстура, идеальная локализация (73)
```

Контур использует настоящую карту v2, Nav2, настоящие trust и адаптер и модель ходьбы; локализация AMCL в этих тестах эмулируется, поэтому прогон не доказывает физическую точность.
Производную карту воспроизводит `python3 -I tools/derive_nav2_map.py` (процедура и манифест: `ws/src/maps/first_map_nav2_v2/manifest.json`). Единый источник поз фикстуры: `tests/nav_e2e/e2e_map.py`.
Живой граф до/после: `tests/nav_e2e/live_graph_snapshot.py` (только подписки). Два Docker-контейнера — целевая архитектура; миграция до физической приёмки не выполнялась.
