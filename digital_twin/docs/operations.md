# Эксплуатация

## Нормальный цикл
`make doctor` → `make vendor` (один раз) → `make build` → `make up` → `make scenario` → `make down`.
Результаты: `results/<RUN_NAME>/results.json` (`checks`, `failed`, `hard_failed`, журнал `events`). `RUN_NAME` по умолчанию содержит время.

## Что считается успехом
`hard_failed` пуст (код выхода сценария 0). `failed` может содержать исходы целей — это измерения поведения MC, а не ошибки харнесса.

## Известные проблемы и что делать
| Симптом | Причина | Действие |
|---|---|---|
| `sim` unhealthy, лог `FAIL: SD never accepted` | mc принимает `SetMcAction SD` только когда есть топики HAL; бывает флаком на старте (в серии 3 из 10 запусков) | `docker compose ... restart sim`; логи в `sim_logs` |
| `Another instance of 'start_sim.sh'` | зомби-процессы | контейнеры должны быть с `init: true` (так и есть в compose) |
| `AMENT_TRACE_SETUP_FILES: unbound variable` | `set -u` вокруг `setup.bash` ROS | подключать окружение при выключенном `-u` (сделано в скриптах) |
| `T3_particles` после `confirm_anchor` | облако частиц стягивается медленнее σ | сценарий продолжает `request_nomotion_update` (документированная процедура) |
| `T5_map_odom_jump` при движении, ABORT, возврат отклонён | AMCL с `alpha=0.2` (Блокер 3), воспроизводимое поведение реального AMCL | не регрессия; см. `control_backend/docs/digital_twin/phase1_results.md` |
| Перезапуск группы Nav2: `failed to send response to .../change_state` | нестабильность ответа сервиса lifecycle | известный дефект (Блокер 6), не маскируется |

## Безопасность запуска
Сеть `internal`; перед первым запуском `make doctor`. Контейнеры не должны подключаться к сети робота. Движений физического робота эта
система не выполняет и не может выполнить (нет маршрута, домен 87, маркер `TWIN_SANDBOX`).

## Правило: всё внутри контейнера
Разработка, запуск скриптов, линт и тесты цифрового двойника выполняются только в контейнере `dev` (образ `x2-twin-test:dev`, исходники смонтированы с хоста):
`make dev-image` (один раз) → `make shell` | `make run CMD="…"` | `make lint` | `make pytest`. На хосте остаются только `docker`/`make` как обёртки,
правка файлов и `scripts/doctor.sh`, `scripts/fetch_vendor.sh` (распаковка архивов AgiBot; перенос в контейнер — открытый пункт).

## Правило цикла (владелец, 27.10.2026)
**Один блокер → один наиболее близкий готовый референс → один контролируемый эксперимент → решение: использовать, адаптировать или отклонить.**
Цикл: воспроизвели ошибку → исправили один компонент → автоматическая проверка → следующая ошибка. В работе только: (A) навигация физического X2 по 2D Goal Pose, (B) одометрия и локализация (карта D1, ручная начальная поза, AMCL, квалификация штатной `leg_odometry`, камеры пока вне контура), (C) цифровой двойник как стенд для воспроизведения конкретных ошибок реального робота. Остальное отложено.
