
SLAM（同步定位与建图）模块提供地图构建、地图获取和重定位接口，支持机器人在未知环境中建立地图并基于已有地图进行精确定位。

重定位

将机器人定位到已建立地图中的指定位置，需先触发重定位指令，再提供初始位姿估计，最后通过订阅定位结果话题确认重定位是否成功。
何时需要重定位

以下场景需要重新执行重定位，使机器人获取在地图中的初始位姿：
机器人开机后首次使用导航功能
切换到新的地图
定位丢失（如机器人被搬动后）
注意：
不执行重定位时，定位模块不会启动，
/slam/lidar_odom
不会有数据发布。

第一行：分辨率（1m 对应 20 个 pixel）
第二行：地图起点坐标（建图原点的像素坐标），即重定位时可使用的初始位姿
第三行：图像长宽（pixel）

坐标转换

导航接口中
target_pose
使用的是
Map 世界坐标
（单位：米）。如果目标点来源于地图像素坐标，需要先将像素坐标转换为世界坐标。
像素坐标可从地图信息文件中获取，路径为：
/agibot/data/var/MapManagerModule/<map_id>/grid_map_info.txt
该文件包含三行：
第一行：分辨率（1m 对应的 pixel 数，例如 20）
第二行：地图起点像素坐标（建图原点
origin.u
,
origin.v
）
第三行：图像长宽（pixel）
像素坐标 → 世界坐标转换公式：
x
=
(
pixel_u
-
origin_u
)
/
resolution
y
=
-
(
pixel_v
-
origin_v
)
/
resolution
其中
resolution
为第一行的分辨率，
origin_u
/
origin_v
为第二行的起点像素坐标。转换后的
(x,
y)
即可作为
target_pose.pose.position
使用。
