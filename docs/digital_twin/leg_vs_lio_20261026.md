# Отклик MC по двум независимым одометриям: `leg_odometry` против LIO (офлайн, 2026-10-26)

Метод: `tools/twin/analyze_leg_vs_lio.py` (сырые данные: `logs/twin/leg_vs_lio_{small,large}.json`). Пачка = подряд идущие ненулевые команды `/aima/mc/locomotion/velocity` (пауза ≤1 с, любой источник). Заданное: ∑|fwd|·dt, ∑ang·dt (dt ≤0,2 с). Фактическое: от старта пачки до +2,5 с после последней команды (**включая выбег**). Расстояние — модуль 3-D смещения, поворот — угол поворота R0ᵀR1; оба не зависят от осей наклонённой IMU, на которой выражена `leg_odometry`. Рядов с командами нет в `manual_amcl_*` (в них нет топика команд), `operator_*` и `g_motion_02` дали 0 рядов по порогам (≥1 с, ≥5° или ≥0,05 м).

| g_motion_01 (18 с) | вперёд (ω мал.) | 0,62 | 1,06 | 1,14 | 1,71 / 1,85 |
| g_motion_03 rc (2,4 с, 0,8) | вперёд | 1,97 | 1,44 | 1,54 | 0,73 / 0,78 |
| g_motion_03 rc (2,2 с, −0,8) | назад | 1,92 | 0,81 | 0,95 | 0,42 / 0,50 |
| g_motion_03 rc (5,9 с, −0,8) | назад | 3,13 | 1,18 | 1,46 | 0,38 / 0,47 |
Вывод: **малые линейные команды (0,17–0,19 м/с) исполняются в 1,3–2,1 раза «дальше» заданного, большие (0,8 м/с, особенно назад) — в 0,4–0,8**: у походки есть эффективная минимальная скорость и разгон; единого коэффициента нет. LIO завышает расстояние относительно `leg_odometry` на 5–25% (+0,03…+0,3 м), но качественно картина та же. Прежние «1,6–1,9×» по LIO подтверждены независимым источником для малых скоростей (диапазон 1,3–2,1).
В официальном sim: команда 0,2 м/с даёт установившуюся скорость ≈0,47–0,54 м/с — тот же эффект «минимальной скорости» (см. `official_sim_results.md`).

## Что это значит для двойника
- Модель MC должна быть **нелинейной по амплитуде**: порог по ω (~0,4–0,5 рад/с для устойчивого старта), минимальная линейная скорость ≈0,45–0,5 м/с, ограничение разгона; не «gain + лаг».
- Для проверки решений (0,5 → 0,6) нужны повторы; одиночные пробы показывают разброс 0,004…0,24 рад/с (см. `friday_data_review.md`).
- Ограничения метода: bursts от пульта (`rc`) имеют переменную амплитуду (берётся медиана), выбег включён, n по условию = 1.
